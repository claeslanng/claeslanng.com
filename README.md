# claeslanng.com

The website of Claes Lanng, DJ & producer from Copenhagen. Served by GitHub Pages at [claeslanng.com](https://claeslanng.com).

One static page (`index.html`), no build step. Edit and push to `main`; the live site updates within a minute or two.

- `assets/img/`: photos in WebP and JPEG at a few sizes, so phones download small versions.
- `assets/logo-original.svg`, `assets/logo-rim.svg`: the logo as vectors (the rim version has a white edge for photos).
- `press/claes-lanng-press-kit.zip`: photos, logo and bio for promoters.
- `CNAME`: the custom domain. Keep this file.

Fonts: Schibsted Grotesk and Archivo, both under the SIL Open Font License (`assets/fonts/`).
